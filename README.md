# vless-warp-panel

VLESS + Reality на **своём домене** с настоящим сайтом-заглушкой, WARP по пользователям и Telegram-бот. Установка одной командой, без веб-панели.

```
Клиент ──VLESS Reality──▶ xray :443 ──▶ интернет напрямую
                              │     └──▶ Cloudflare WARP (кому включён)
                              └─ чужие (браузер, сканер) ──▶ nginx: обычный сайт с сертификатом
```

**Зачем «сам у себя».** Обычный Reality притворяется чужим сайтом (yahoo, apple), и у него не сходятся имя сайта и IP сервера — это видно. Здесь Reality притворяется *твоим* сайтом: домен, IP и сертификат совпадают, шифрование отдаёт настоящий nginx. Для браузера и сканера это просто сайт небольшой студии.

## Что нужно

- VPS: Ubuntu 22.04/24.04 или Debian, root, свободные порты **80** и **443**.
- Домен (подойдёт дешёвый `.site`/`.store`). A-запись → IP сервера. Если DNS в Cloudflare — **серая тучка** (DNS only).
- Приложение: Hiddify, v2rayNG, Happ (Android); Happ, Streisand, v2RayTun (iPhone); Hiddify, v2rayN (Windows).

## Установка

На сервере под root:

```
bash <(curl -Ls https://raw.githubusercontent.com/ln71v/vless-warp-panel/main/install.sh)
```

Спросит домен, название сервера (подпись ключей), название сайта-заглушки и имя первого пользователя. Через пару минут покажет QR и ссылку `vless://`.

Docker и всё, что в нём (например AmneziaWG), установщик **не трогает**.

## Меню: `vpn`

| Что | Как |
|---|---|
| Статус: xray, nginx, сертификат, IP, WARP, кто онлайн | пункт 1 или `vpn status` |
| Пользователи: онлайн с IP, трафик ↓↑, WARP | пункт 2 |
| Ключ (QR + ссылка), добавить, удалить | пункты 3–5 |
| Пауза ключа: отключить / включить, ключ не меняется | пункты 6–7 |
| WARP: установить, вкл/выкл по пользователю, всем, удалить | пункты 8–12 |
| Telegram-бот: установить, лог | пункты 13–14 |
| Обновить панель | пункт «Обновить» или `vpn update` (и сама каждую ночь) |

## Telegram-бот

В меню «Бот: установить» → токен от [@BotFather](https://t.me/BotFather). Свой ID можно не знать: оставь 0, напиши боту `/id`, потом повтори установку с этим числом. Бот отвечает только владельцу.

Кнопки: **👥 Пользователи** (у каждого: 🔑 ключ с QR, 🌐 WARP вкл/выкл, ⏸ пауза), **➕ Добавить**, **🌐 WARP** (всем вкл/выкл, перевыпуск ключа), **📊 Статус**. Удаления в боте нет — только пауза, удалить можно в меню.

## WARP

xray сам ходит в Cloudflare через встроенный wireguard-выход, без отдельных интерфейсов и контейнеров. Ключ WARP получает [wgcf](https://github.com/ViRb3/wgcf). Кому идти через WARP — решаешь по каждому пользователю.

## Где что лежит

| Путь | Что |
|---|---|
| `/opt/vless-warp-panel/` | панель (git), обновляется `vpn update` |
| `/usr/local/etc/xray/config.json` | конфиг xray, перед каждой правкой — `.bak` |
| `/usr/local/etc/xray/vpn-meta.json` | название, домен, WARP, отключённые ключи |
| `/usr/local/etc/xray/vpn-traffic.json` | накопленный трафик по пользователям |
| `/var/www/<домен>/` | сайт-заглушка, меняй как хочешь |
| `/etc/nginx/sites-available/<домен>` | nginx: 80 — сертификат и редирект, 127.0.0.1:8443 — сайт |
| `/etc/vpn-bot.env` | токен бота и ID владельца (права 600) |

## Если что-то не так

| Симптом | Что делать |
|---|---|
| Установщик: «домен указывает не на этот сервер» | Проверь A-запись, выключи прокси Cloudflare (оранжевую тучку), подожди 5 минут |
| Сертификат не выпустился | Открой порт 80 у хостера |
| Ключ не подключается | `vpn status`; открыт ли 443 у хостера |
| Бот молчит | `journalctl -u vpn-bot -n 30 --no-pager` |
